# COMANDOS SIMPLES DO GIT!
 
Este repositório traz um resumo dos principais comandos do git, mas também documentação completa pelo link da pagína [documentação oficial do git em português.](https://git-scm.com/docs/git/pt_BR)

>-----------------------------------------------------------------
>
**Principais Comandos**👌

|comandos|       descrição     |
|  ---   |  ---    |
|mkdir   | Make directory (`criar diretório`)|
|cd      | Change drectory (`mudar diretório`)|
|init    | inicializa um repositório .git
|add     | adiciona o diretório pra staged (`área de preparação`)
|ls      | lista os itens do diretório|
|cat     | exibe ou faz a cocatenação de 2 ou mais arquivos
|clone   |clona pastas e arquivos de um diretório
|touch   |utilizado para criar **documentos e arquivos**
|status  |mostra o estado do diretório e seus arquivos
